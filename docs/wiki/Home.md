# DaVinci Resolve AI Director Wiki

DaVinci Resolve AI Director is a local-first Windows companion for DaVinci Resolve. It combines local GGUF inference, managed Direct/Upstream llama.cpp-derived runtimes and controlled Resolve automation.

**Current release:** **0.3.25** is published as an **unsigned** [GitHub Release](https://github.com/nikolaoskalomiris/davinci-resolve-ai-director/releases/tag/0.3.25). Verify the published SHA-256 values before running either installer. Gate 6D remains a post-publication reproducibility check.
