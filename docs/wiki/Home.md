# DaVinci Resolve AI Director Wiki

DaVinci Resolve AI Director is a local-first Windows companion for DaVinci Resolve. It combines local GGUF inference, managed Direct/Upstream llama.cpp-derived runtimes and controlled Resolve automation.

Start here:

- [Installation](Installation.md) — release assets, checksums, SmartScreen, supported clean-upgrade procedure and first run.
- [Build from Source](Build-from-Source.md) — source authorities, current prerequisites and clean-build status.
- [Architecture](Architecture.md) — application, runtime base, dual server stack and Resolve launcher.
- [Direct and Upstream Runtimes](Direct-and-Upstream-Runtimes.md) — what each profile means.
- [Updater and Rollback](Updater-and-Rollback.md) — transactional update safety model.
- [Resolve Integration](Resolve-Integration.md) — install scope and launcher behavior.
- [Troubleshooting](Troubleshooting.md) — common install/runtime/update problems.

Authoritative technical details live in the repository's structured `docs/` tree; the Wiki is the navigational/tutorial layer rather than a second independent specification.
