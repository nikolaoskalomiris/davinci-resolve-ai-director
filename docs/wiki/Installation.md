# Installation

1. Download the [latest GitHub Release](https://github.com/nikolaoskalomiris/davinci-resolve-ai-director/releases/latest).
2. Run the main AI Director installer.
3. Leave **Resolve Integration** enabled if you want to launch AI Director from DaVinci Resolve.
4. Start AI Director, choose **Direct** or **Upstream**, then select a local GGUF model.

> **Upgrading:** uninstall the existing AI Director application first. If Resolve Integration is installed, uninstall that Windows entry too, then install the new release.

If Windows SmartScreen warns, confirm the file came from the official release page and check that release's signing status. See [Release Verification](https://github.com/nikolaoskalomiris/davinci-resolve-ai-director/blob/main/docs/release/RELEASE_VERIFICATION.md) for checksum instructions.

For requirements, first-run details and uninstall instructions, see the full [Installation guide](https://github.com/nikolaoskalomiris/davinci-resolve-ai-director/blob/main/docs/user/INSTALLATION.md).
